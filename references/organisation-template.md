# Organisation-local configuration template

Copy this file to `references/organisation.local.md` for local configuration in a checkout connected to the public repository. That destination is gitignored. Do not place passwords, tokens, recovery material, private keys, or raw profile exports in it.

An organisation may track an adapted version only in a deliberately private internal repository with an approved access and publishing model.
